# sigil v0.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `@0nb/sigil` v0.1.0 — the 0nb design system as Svelte 5 components plus Tailwind v4 theme, installable from GitHub at a tag, with a local playground that doubles as the reference.

**Architecture:** A source-only package (no build step): `src/lib` holds `tokens.css` (plain custom properties), `theme.css` (Tailwind v4 `@theme` over those tokens + base + two utilities), `.svelte` components and plain `.js` modules. Consumers compile it with their own Vite + Svelte + Tailwind. Tests run in three Vitest projects: `dom` (jsdom, behavior), `ssr` (node, `svelte/server` rendering, no-JS guarantees) and `node` (tokens, scales, brand script, size budget via a consumer-shaped Vite build).

**Tech Stack:** Svelte 5 (runes, `$props.id()`), Tailwind CSS v4 (`@tailwindcss/vite`), Vite, Vitest (projects), jsdom, @testing-library/svelte + jest-dom + user-event, svelte-check, Prettier + prettier-plugin-svelte, @resvg/resvg-js (dev-only, brand script). Package manager: pnpm.

**Spec:** `docs/superpowers/specs/2026-10-24-sigil-design.md`

## Global Constraints

- Colors exactly: ground `#000000`, fg `#e6e6e6`, dim `#8a8a8a`, ghost `#4a4a4a`, rule `#2a2a2a`, grid `rgb(255 255 255 / 0.07)`. Dark only; `color-scheme: dark`.
- Font stack exactly: `ui-monospace, SFMono-Regular, Menlo, Consolas, "Liberation Mono", monospace`. No web fonts, no icon fonts, no images except inline svg.
- Type scale: 10 (tag), 11 (label), 12 (small), 13 (body), 15 (input), 28 (display) px; tags tracked `0.3em`, buttons `0.2em`; numbers `tabular-nums`.
- All copy is lowercase in the source text (never `text-transform`). No emoji, no marketing tone.
- No radius, shadows, gradients (except the grid vignette mask), colored accents, boxes/cards around groups. Messages are monochrome: `err` / `ok` prefixes, no red/green.
- `#4a4a4a` is decoration only and is `aria-hidden` when purely decorative; readable text uses fg or dim (≥ 4.5:1 on black).
- Svelte peer `^5`, tailwindcss peer `^4`. Zero runtime `dependencies`.
- Budget: theme + base CSS ≤ 8 KB gzipped in a consumer build; a page using 6–8 components adds ≤ 10 KB gzipped JS over an empty Svelte app; `Horizon` never in the main bundle.
- Nothing touches `window`/`document`/`navigator` at import time or during server render; every component renders through `svelte/server`.
- Input components are real form controls (`name`, `value`, `<button type="submit">`); pages work as plain HTML forms without JS. `Expired` and `NotFound` render no `<script>`.
- Motion (cursor blink, spinner, horizon) stops under `prefers-reduced-motion: reduce`.
- `package.json`: `"name": "@0nb/sigil"`, `"license": "UNLICENSED"`, `"type": "module"`. `LICENSE` text is exactly the block in spec §6.3.
- Every commit: author `0x0nb <0x@0nb.dev>`, GPG-signed (repo-local config already set), message without any co-author or AI trailer.

## Review Focus

- Very long user content (a 2,000-char destination url, a 300-char description) in `Ls`, `Readout`, `Prompt` must stay inside its column on a 400px-wide screen: truncated with the full value in `title`, never widening the page → test in Task 5.
- Degenerate chart data: `Scope`/`Spark` with 0 points, 1 point, or all-equal values must render without `NaN` in any path or coordinate → tests in Task 6.
- Out-of-range paging: `Pager` with `pages` 0 or 1, or `page` above `pages`/below 1, must clamp and never render a link to page 0 or past the end → test in Task 5.
- Clipboard refused (permissions, insecure context): `Code` copy must show `err` with how to copy manually, not fail silently → test in Task 7.
- Reduced motion: `Spinner` shows a static `…` and `Horizon` stays on the static sigil (the prompt uses the native caret, no custom blink) → tests in Tasks 2, 8.
